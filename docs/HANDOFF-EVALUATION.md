# Evaluate a model handoff

The goal is successful work by an unfamiliar agent using the installed plugin, without this conversation or private workspace helpers. Current native installation and simulated Pi transport checks do not establish that ability. Lower-capability model performance remains unmeasured.

Use a frozen plugin revision, record the actual host/model configuration, and give every candidate the same task and resource budget. Keep credentials absent for these trials. Synthetic model transport is useful for interface checks but must be reported separately from real-model work.

| Trial | What the agent receives | What to observe |
|---|---|---|
| Navigate | An incomplete project with a missing current render | Finds status, preserves valid speech, identifies the actual next dependency |
| Repair animation | An outline restoration that accidentally fills the shape | Retrieves a relevant repair, fixes stroke/fill handling, inspects a new render |
| Repair synchronization | A repeated cue prefix in an otherwise valid script | Detects ambiguity before synthesis; selects a unique phrase; retains measured timing semantics |
| Preserve mathematics | A unit conversion with inconsistent labels and distance values | Corrects the mapping and calculation, rather than cosmetically changing the diagram |
| Honor evidence | A modified narration plus an old accepted export | Rejects stale acceptance and rebuilds the affected artifacts |
| Create | A novel, bounded mathematical explanation | Correct mathematics, coherent visual mechanism, legible captions and honest scoped review |

Compare the original package with the distilled package across multiple tasks and repeated attempts. Record successful outcomes, semantic defects, unsuccessful tool calls, repair attempts, elapsed time, actual reported usage when available, and interventions. Have an independent reviewer inspect outputs without knowing which package was used when feasible. Do not infer a general model ranking from one successful film.

For the creative trial, specify the mathematical target but allow composition and visual style within the channel profile. Judge teaching clarity separately from code execution. Passing a few primitives does not establish proof-writing ability, aesthetic judgment, or audiovisual perception.

Record failure cases with their actual error or evidence timestamp. Promote a repair into bundled knowledge only after verifying it, and retain its applicability limits. When a model repeatedly fails the same semantic task, simplify the explanation or involve a more capable reviewer; never turn an exhausted retry budget into an automatic pass.

No real lower-model comparison has been run for this evaluation protocol yet.
