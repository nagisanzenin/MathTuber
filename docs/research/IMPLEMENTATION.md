# Implementation status — 5 September 2026

Implemented in this revision:

- Portable skill instructions keep authorship with the host agent and separate attention, enjoyment, comprehension, transfer and return.
- Optional manifest creative contracts record audience, goal, question, payoff, transfer prompt, duration rationale, novelty audit and per-scene viewer-state beats. `plan-check` verifies completeness, not creativity.
- Explicit Shorts delivery rejects landscape or exports over 180 seconds. Regular-video briefs can allow 240–300 seconds.
- Full-timeline original/licensed audio stems support sparse music and event sounds. Assembly ducks the stem under speech and normalizes the final mix.
- Creative-project review requires methods, coverage, limitations and audience-validation status for each domain. Evidence remains hashed and linked to the current project snapshot.
- A five-topic production batch tests these mechanisms with exact mathematical checks and local synthesis/rendering.

Not yet implemented or established:

- Automatic audience experiments, delayed transfer tests, retention-data ingestion, validated engagement scores, or proof that these changes improve quality or retention.
- An engine that judges imagination or decides editorial choices. Those remain the host agent's responsibility.
- Subjective acoustic review on a text/image-only host. ASR and signal measurements cover speech content and technical delivery, not pleasantness, taste or music balance.

SYSTEM.md and design-policy.json retain the broader proposal. They must not be mistaken for an executable schema or a list of completed features.
