# Local-rule visual prototype

A silent 31-second Truchet composition study, not an upload-ready narrated film. Run with the plugin directory on `PYTHONPATH` and an installed Manim runtime:

```sh
python -m manim -ql truchet.py Prototype
```

The source reads the channel profile from the installed `components` module location. Original vector art; no external textures or copied illustrations. Eight sampled frames were inspected after fixing stroke-opacity restoration. The eventual film still needs an enlarged local-join explanation, measured narration, captions and full final review. See [research](../../../docs/research/PATTERN-AS-EXPLANATION.md).
