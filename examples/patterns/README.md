# Patterns with discoverable rules

Five original vector films explore tile-path connectivity, equal-circle packing, twill interlacing, a ruled hyperboloid and polar-rose parity. Each connects an organizing rule to a whole image.

[Research and limits](../../docs/research/PATTERN-AS-EXPLANATION.md) distinguish adjacent aesthetic evidence from an editorial hypothesis. Initialize a project from its manifest, copy scenes/assets, synthesize narration, compile cues, render a captioned preview and inspect the final output before publishing. Timing assets must be recompiled after narration changes.

Mathematical checks and assumptions accompany each project. No copied artwork, credentials, private publishing state or media are included. Sampled visual inspection and transcription do not establish viewer learning, artistic preference or natural prosody.
