# Mathematical observations across domains

Five original vector films explore classifier precision, absolute-error medians, single-item reservoir sampling, telescoping sums and scheduling. Each makes a different mathematical argument visible.

[Research and limits](../../docs/research/MATH-FIRST-EDITORIAL-MIX.md) distinguish adjacent aesthetic evidence from an editorial hypothesis. Initialize a project from its manifest, copy scenes/assets, synthesize narration, compile cues, render a captioned preview and inspect the final output before publishing. Timing assets must be recompiled after narration changes.

Mathematical checks and assumptions accompany each project. No copied artwork, credentials, private publishing state or media are included. Sampled visual inspection and transcription do not establish viewer learning, artistic preference or natural prosody.
