# Five continuous mathematical settings

Profile 0.6 binds caption typography to the channel. Each film keeps a concrete setting through its explanation: a random cloud, film junction, drop, drawn curve or globe. These are design hypotheses, not audience-tested outcomes.

- Diffusion: exact expected squared displacement, separated from a finite simulation.
- Soap films: equal force balance and a three-pin length comparison.
- Rainbows: Snell refraction, one reflection, and a stationary exit angle.
- Bezier curves: repeated interpolation and convex-hull containment.
- Globe routes: a great-circle arc compared with latitude travel and a true 3D rotation.

Use each manifest to initialize a production project, copy scenes and assets, synthesize speech, compile cues, compile sound events, then render and inspect previews before final rendering and assembly. Timings depend on local synthesis. Recompiling invalidates prior evidence. Sources omit media, weights, credentials and private channel data.

All mathematical checks are in the included math-verification files. Independent derivations are not generated from rendered labels. Fonts are installed dependencies and retain their own licenses. Code and original narration use the repository license. Ray color is a darker amber variant to improve contrast; dry narration is intentional.

Read [research and limits](../../docs/research/CONTEMPLATIVE-SETTINGS.md) and [caption settings](../../docs/CAPTION-STYLES.md). ASR and signal inspection do not establish pleasant prosody. Sampled images do not establish uninterrupted viewing or actual audience response.
