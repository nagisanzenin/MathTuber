# Mathematical relations across domains

Five original vector films explore Chinese remainders, a signed image filter, logarithmic power levels, a two-state Markov chain and maximum flow. Each makes a different mathematical argument visible.

[Research and limits](../../docs/research/EXAMPLES-AND-PRINCIPLES.md) distinguish printed worked-example evidence from a video-production hypothesis. Initialize a project from its manifest, copy scenes/assets, synthesize narration, compile cues, render a captioned preview and inspect the final output before publishing. Timing assets must be recompiled after narration changes.

Mathematical checks and assumptions accompany each project. No copied artwork, credentials, private publishing state or media are included. Sampled visual inspection and transcription do not establish viewer learning, artistic preference or natural prosody.

Run `python3 examples/relations/verify_math.py` from the repository root to reproduce the finite mathematical checks without media dependencies. These checks supplement the accompanying proofs and assumptions.
