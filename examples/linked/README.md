# Linked-representation batch

Five independently checked mathematical scenes, pinned to workshop profile 0.3. Each has a different setting and an explicit critical-interval review plan. The source uses native host reasoning and local Manim/Kokoro; no paid model API calls are required by the engine.

| Example | Explanatory bridge |
| --- | --- |
| Chaos game | One point and its halfway image become a region map; square contrast tests the rule. |
| Pursuit | Exact constant-speed paths connect to a shrinking side and complementary distance bar. |
| Reflection | A shared bank point drives physical and reflected routes plus total length. |
| Fair game | A numbered token position maps to the same probability-graph position. |
| Missing square | Exact rigid pieces connect to labeled, magnified boundary deviations. |

Initialize a production folder with `engine.py init --project /local/production --manifest manifest.json`, copy the example's `scenes` and `assets` into that folder, run audio, then `compile_cues.py --project /local/production`. Run `score.py --project /local/production` using the media Python to synthesize the original CC0 boundary tones before rendering. Render a preview with trusted native execution, inspect the difficult passages, render final, assemble and verify. WAVs, models, credentials and generated videos are not distributed in this source tree.

`assets/review-plan.json` resolves against `assets/timing.json` through `mathtuber.review_sampling.interval_samples`. Extract and actually inspect those frames with host media tools; the plan is not a review verdict. Follow the production skill for evidence-scoped final review and the complete-batch publishing gate. Recompile timing after any narration change. Verify the whole final mix technically and disclose whether subjective listening was available.

Original code, narration and vectors use the repository license. Fonts and speech models retain their own licenses. The missing-square source link discusses a related diagonal-gap dissection; this exact four-piece construction is independently derived in its `math-verification.json`. All five have exact arguments or clearly bounded illustrations; no finite simulation is presented as a probability proof.

See [research and limitations](../../docs/research/LINKED-REPRESENTATIONS.md). Viewer retention, learning and aesthetic preference have not yet been measured.
