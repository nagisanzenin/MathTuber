# Mathematical comparisons

Five editable films explain squared-error averaging, composition order, dice sums, unequal-probability sampling and memoryless waiting. Each includes a concrete changed case at the ending.

Initialize from the manifest, copy scenes/assets, synthesize narration, recompile measured cues, render and inspect current final media before publication. Source mathematics and assumptions are recorded with each example.
