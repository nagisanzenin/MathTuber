# Gentle observations: five mathematical scenes

These examples use profile 0.5: warm materials, patient narration, and visible relationships. They are an initial interpretation of the channel direction, not a claim of proven audience response.

| Film | Mathematical observation |
| --- | --- |
| Ants | Equal-speed instantaneous reversals preserve unlabeled departure times. |
| Balance | Three possible answers reduce nine candidates to three to one. |
| Doors | Divisor pairs explain why square-numbered doors remain open. |
| Constant width | Three equal-radius arcs keep parallel supports a fixed distance apart. |
| Stickers | Fewer unseen types increase the expected wait for something new. |

Initialize a production project using its `manifest.json`, copy its scenes and assets, synthesize local speech, run `scripts/compile_cues.py --project /local/production`, then `scripts/score_events.py --project /local/production`. Render a preview in trusted native execution, inspect the declared critical intervals, repair as needed, then render final, assemble, and verify. Recompile timings and sounds after narration changes. Use current engine commands from the production skill.

Caption phrases preserve spoken words and are checked against the synthesized word stream. The included timing is an example artifact, not a promise that another machine or model version produces identical speech. Do not reuse review acceptance across changed renders.

Code, narration and vectors use the repository license; original synthesized event sounds are CC0. Fonts and local speech models retain their own licenses. Media, model weights, credentials and private channel data are omitted. Every mathematical argument is independently checked in `math-verification.json`. No simulation substitutes for a general proof.

Read [channel direction](../../docs/CHANNEL-DIRECTION.md) and [research boundaries](../../docs/research/EVENTS-AND-PREDICTIONS.md). Actual viewer learning, aesthetic response, and anxiety reduction remain unmeasured. Final release records disclose technical audio checks separately from subjective listening.
