# Five mathematical mechanisms

Parity error location, gradient descent stability, Simpson aggregation reversal, Fibonacci tilings, and Braess routing incentives. Each has one explicit mathematical objective and a changed condition or boundary case.

These are editable sources, not pre-approved exports. Initialize a new project from its manifest with `engine.py init --project PATH --manifest FILE --profile ivisualizethings-workshop`, copy scenes and assets into it, synthesize local narration and recompile speech cues. Render a captioned prototype and inspect it before the complete final render. Follow the installed production and publishing guides; source manifests and this archive do not transfer acceptance to newly rendered videos.

Warm-paper identity is pinned through the channel profile. Exact geometry takes precedence over rounded decorative components. Dry narration avoids an untested music layer. The mathematical checks do not establish viewer engagement or learning.
