# Five mathematical discoveries

These are editable source projects, not rendered media or channel credentials. Each manifest includes its audience-state contract, English narration, original visual actions, Shorts delivery budget and sound policy.

- Perfect out-shuffles: reconstruct a deck through permutation orbits.
- Chomp: steal a hypothetical winning reply; distinguish existence from a recipe.
- Four/seven cookie boxes: prove the last impossible order with residue ladders.
- Coin-pattern waiting: retained progress separates HH from HT.
- Catalan paths: a reversible prefix reflection counts the bad routes.

Create a run using `engine.py init --project RUN --manifest EXAMPLE/manifest.json`, copy the example scenes directory into RUN, and synthesize audio. Run `compile_cues.py --project RUN` after speech generation, then `synthesize_score.py --project RUN` with the media Python. This writes an original sparse score under assets; no downloaded music is used. Generate these assets before rendering. Run `plan-check`, inspect previews, render final scenes, assemble and review. Publication remains a separate authorized step.

The committed mathematical checks distinguish exact finite enumeration from the general proof. They are not audience studies. These videos test a first implementation of the research guide; improved retention or learning has not yet been established.
