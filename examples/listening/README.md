# Explanatory listening studies

Five original films use acoustic relationships as part of their explanation: bottle cavity resonance, wind-chime bending length, echo round-trip delay, missing-fundamental pitch and pluck-position mode selection.

[Research and limits](../../docs/research/EXPLANATORY-LISTENING.md) distinguish laboratory evidence, physical models and editorial hypotheses. Initialize a project from its manifest, copy scenes/assets, synthesize speech, compile cues and run `scripts/score_events.py` before rendering. This resolves `listening-windows.json` against current paragraph pauses and writes a local score. Recompile after narration changes. The example timing files are reference outputs, not portable substitutes for new measured speech.

Tones are mathematical illustrations, not instrument recordings. Exact model assumptions and independent checks accompany each project. A full current final review is required before publishing. Passing spectrum/timing tests or inspecting sampled images does not establish subjective sound quality, artistic success or audience learning. Credentials, private publishing intents, database state and media are excluded.
