# Mathematics across applications

Five editable films explain stable softmax, amortized array growth, inclusion-exclusion, randomized response and reversing percentage changes. Each includes a concrete changed case at the ending.

Initialize from the manifest, copy scenes/assets, synthesize narration, recompile measured cues, render and inspect current final media before publication. Source mathematics and assumptions are recorded with each example.

[Ending guidance](../../docs/research/ENDING-WITH-A-NEW-CASE.md) separates learning research from unmeasured Shorts hypotheses. Sampled review is not continuous audiovisual review or audience validation.
