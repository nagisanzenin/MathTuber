# Mathematics through controlled contrasts

Five original vector films explore unit-sensitive nearest neighbors, conditioning, an integer recurrence approaching square root two, stars and bars, and independent versus shared failures. Each makes a different mathematical argument visible.

[Research and limits](../../docs/research/CONTRAST-WITHOUT-OVERLOAD.md) distinguish comparison-learning evidence from a video-production hypothesis. Initialize a project from its manifest, copy scenes/assets, synthesize narration, compile cues, render a captioned preview and inspect the final output before publishing. Timing assets must be recompiled after narration changes.

Mathematical checks and assumptions accompany each project. No copied artwork, credentials, private publishing state or media are included. Sampled visual inspection and transcription do not establish viewer learning, artistic preference or natural prosody.
