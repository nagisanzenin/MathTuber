# Author a visible reasoning step

Use this when narration states a relationship that the picture currently only labels. The goal is a more inspectable explanation; motion is optional.

For each central step, write four short fields in the project assets or storyboard:

- **Before:** what is already visible and what the viewer can reasonably know.
- **Change:** the exact operation, displacement or comparison that carries the reasoning.
- **Preserved:** the object identity, measure, boundary or reference that must survive the change.
- **After:** the new inference available in the resulting image.

Coordinate the relevant phrase with the actual operation. For a rearrangement, keep pieces identifiable throughout; compute endpoints instead of approximating them visually. For a physical model, distinguish a slowed demonstration from a changed physical law. For a comparison, show the reference in the same units. A cue should follow the relevant relation without implying a false causal propagation.

Inspect the captioned transition and a version considered without narration: can the reviewer identify what changed, what stayed equal, and what conclusion the image supports? A silent inspection is an editorial diagnostic, not proof that an unprompted viewer will understand. Keep the endpoint available when viewers need to compare. Do not add motion to a useful still or fade away a premise just to simplify the screen.

Use ordinary Manim geometry and transformations or any suitable renderer. Existing cue timestamps and critical-interval review support this workflow. No required effect, animation count, generic reveal sound or numerical aesthetic score is added.
